# File Function Map

Every file in this repository has a specific purpose. Use this map to find what you need.

---

## Core Protocol Files (`research-protocol/`)

| File | Purpose | When to Use |
|---|---|---|
| [`RESEARCH.md`](../research-protocol/RESEARCH.md) | Main router and research lifecycle guide | Every research session - start here |
| [`AGENTS.md`](../research-protocol/AGENTS.md) | AI coding agent configuration rules | Optional: for IDE coding agents (Cursor, Windsurf, Copilot); not needed for web chats |
| [`00-RESEARCH-CORE.md`](../research-protocol/00-RESEARCH-CORE.md) | Universal research integrity rules | Every research task - always loaded |
| [`01-research-writing.md`](../research-protocol/01-research-writing.md) | Academic writing standards and paraphrasing | Writing papers, thesis chapters, or proposals |
| [`02-research-human.md`](../research-protocol/02-research-human.md) | Human subjects, consent, and ethics | Research involving interviews, surveys, or human evaluations |
| [`03-research-literature.md`](../research-protocol/03-research-literature.md) | Source evaluation, synthesis, and research gaps | Literature reviews and finding research topics |
| [`04-research-methodology.md`](../research-protocol/04-research-methodology.md) | Research design, variables, and sampling | Designing study methodology and defining research questions |
| [`05-research-experiment.md`](../research-protocol/05-research-experiment.md) | Experiment execution and leakage prevention | Running experiments, preventing leakage, reproducibility |
| [`06-research-analysis.md`](../research-protocol/06-research-analysis.md) | Statistical analysis and uncertainty | Analyzing data, interpreting results, hypothesis testing |
| [`07-research-audit.md`](../research-protocol/07-research-audit.md) | Cross-module alignment and final audit | Final review before submission or defense |
| [`08-research-decision-log.md`](../research-protocol/08-research-decision-log.md) | Template for tracking research decisions | Throughout the research project |
| [`09-project-context-template.md`](../research-protocol/09-project-context-template.md) | Template for creating your `PROJECT-CONTEXT.md` | Initial project setup to define topic, questions, and parameters |
| [`10-research-domain-adaptation.md`](../research-protocol/10-research-domain-adaptation.md) | Domain-specific research guidance | Adapting the framework to non-CS disciplines |
| [`11-research-background-generator.md`](../research-protocol/11-research-background-generator.md) | Step-by-step background construction | Writing the introduction/background section |
