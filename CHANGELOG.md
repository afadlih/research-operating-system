# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-20

### Added

- **Core Protocol** (`00-RESEARCH-CORE.md`) - universal research integrity rules, evidence discipline, and verification gates.
- **Writing Module** (`01-research-writing.md`) - academic writing standards, paraphrasing rules, and citation integrity.
- **Human Subjects Module** (`02-research-human.md`) - participant handling, consent, privacy, and human evaluation protocols.
- **Literature Module** (`03-research-literature.md`) - source evaluation, evidence hierarchy, synthesis, and gap construction.
- **Methodology Module** (`04-research-methodology.md`) - research design, variables, sampling, validity, and methodological justification.
- **Experiment Module** (`05-research-experiment.md`) - experiment execution, leakage prevention, baseline fairness, and reproducibility.
- **Analysis Module** (`06-research-analysis.md`) - statistical testing, effect size, uncertainty, and conclusion discipline.
- **Audit Module** (`07-research-audit.md`) - cross-module alignment audit and final research readiness assessment.
- **Decision Log Template** (`08-research-decision-log.md`) - structured decision tracking and rationale preservation.
- **Project Context Template** (`09-project-context-template.md`) - project-specific research context record.
- **Domain Adaptation** (`10-research-domain-adaptation.md`) - multi-domain support (CS, Education, Psychology, Health, Business, Economics, Social Science, Law, Humanities).
- **Background Generator** (`11-research-background-generator.md`) - research background construction and gap development guide.
- **Router** (`RESEARCH.md`) - main orchestration file with task routing table and research lifecycle phases.
- **Agent Config** (`AGENTS.md`) - AI agent integration rules for coding agents and IDE assistants.
- **Prompt Library** - ready-to-use prompts for starting research, literature review, and reviewer mode.
- **User Guides** - English and Bahasa Indonesia user guides.
- **Platform Maps** - setup instructions for ChatGPT, Gemini, Claude, NotebookLM, and coding agents.
- **Workflow Diagram** - visual overview of the research operating system workflow.
